# Zenix Music Player

Zenix 是独立开发的 Windows 桌面音乐播放器。界面根据本地运行的 Folia Major 进行观察和重制；本仓库没有引入参考项目的 Git 历史或界面素材。

## 启动

需要 Node.js 22 或更新版本。

```powershell
npm ci
npm run build
npm start
```

开发时运行 `npm run dev`，同时启动 Vite 与 Electron。

## 已实现

- 导入音乐文件夹或单个文件，读取标题、艺人、专辑、时长及封面，并保存在本机曲库。
- 播放本地音频，支持播放队列、上一首/下一首、随机与循环、进度和音量控制、系统媒体键。
- 读取内嵌或同名歌词文件；支持 LRC、VTT、TTML、YRC、QRC 的基本时间轴。
- 创建、编辑、导入和导出本地 M3U 歌单。
- 无需账号的网易云音乐搜索、分页、试听和歌词读取。试听取决于曲目可用性，部分歌曲只有短片段。
- 无边框窗口、玻璃控件、主页收藏卡片、顶部悬停搜索功能条和 Lattice 贴纸墙。搜索在玻璃条内展开，并融合个人背景，不切换到黑色页面。贴纸来自播放队列及最近播放记录，以不同宽高的海报铺满画面；悬停可突出海报，拖拽或滚轮可浏览。点击时原海报扩张，邻近海报换位，视角跟随移动；展开后可播放该歌曲。最近播放记录保存在本机。
- 使用 lottie-web 渲染自制矢量开屏动画，启动时绘出 Z 字标记与环形声波；可跳过，也可在“选项 → 帮助”中重播。系统减少动效设置生效。
- 首次启动可选择照片或视频作为个人背景，之后在个人主页或设置中更换。自定义背景随主页、搜索、设置等场景调整遮罩，贴纸墙完成过渡后只展示歌曲封面。
- 个人主页可编辑空间名称与简介、快速搜索和管理收藏。播放列表可切换喜欢、收藏、历史及自定义歌单；每首歌可标记喜欢或收藏并添加到歌单。播放列表的 × 只从当前队列移除，真正删除在音乐管理中完成。
- 喜欢、收藏、歌单和逐次播放历史写入本机 `personal-library.json`。贴纸页左下角可拖动进度条，旁边的歌词按钮直接打开桌面 LRC。歌词以独立玻璃悬浮窗显示，支持拖动、换色和上首/播放/下首，位置与开关状态会保存在本机。进入、取消、滑动贴纸使用项目自制的独立 WAV 音效，每类可选择五种，并可调整音量或关闭。

本项目不含登录、账号接入或登录校验。网易云在线接口由第三方 API 包提供；在线歌曲和封面来自服务端，可能因地区、版权或接口变化而不可用。

原创桌面图标由 `assets/generate-icon.py` 生成。项目源文件与素材不依赖参考项目目录。
