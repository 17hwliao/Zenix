# Zenix 自定义音乐源设计

## 目标与现状

- 在线歌曲的搜索、播放地址、歌词、封面与可下载文件全部由用户添加的自定义源提供。应用本身不预置平台采集接口，也不要求登录。
- 本地文件夹、音频文件、M3U、个人歌单与桌面歌词继续独立工作。
- 旧的网易云测试接口已移除。已保存在喜欢、收藏、历史及播放队列中的在线歌曲记录暂时保留，但不再向旧接口发出请求；没有对应自定义源时显示来源不可用。
- LX Music 的自定义源主要为已有的歌曲信息返回音频地址；它的目录搜索是另一套内置模块。因此 Zenix 的完整自定义源协议必须覆盖搜索与解析，不能只实现 `musicUrl`。参考：[LX 自定义源文档](https://lxmusic.toside.cn/desktop/custom-source)、[LX 项目说明](https://github.com/lyswhut/lx-music-desktop#%E4%B8%80%E6%95%B0%E6%8D%AE%E6%9D%A5%E6%BA%90)。

## V1 脚本协议

一个源由清单和 JavaScript 入口组成。清单包含 `id`、名称、版本、脚本协议版本、声明的网络域名、支持能力及音质；导入时检查字段和版本，并让用户看到该源需要访问的域名。每个源单独启用、停用和卸载。

| 能力 | 输入 | 输出 |
| --- | --- | --- |
| `search` | 关键词、页码、页大小 | 歌曲元数据、总数或下一页游标 |
| `resolvePlayback` | 来源歌曲 ID、期望音质 | 音频 URL、实际音质、有效期、必要请求头 |
| `lyrics` | 来源歌曲 ID | 原文及可选翻译、逐字歌词 |
| `artwork` | 来源歌曲 ID | 封面 URL 或可缓存的图片数据 |
| `resolveDownload`（可选） | 来源歌曲 ID、期望音质 | 可保存文件的 URL、格式、必要请求头及有效期 |

搜索结果必须包含稳定的 `remoteId`、歌名、歌手和时长。应用生成 `sourceId:remoteId` 作为歌曲 ID；播放 URL、下载 URL 不写进歌单或历史。源可以仅支持搜索或仅支持解析，但界面应明确显示缺少的能力。`resolveDownload` 与试听能力分开声明，不能因为有试听 URL 就自动显示下载按钮。

## 运行边界

自定义 JavaScript 不能在 Electron 主进程或拥有 Node 权限的页面中执行。每个源运行在隔离的无 Node 环境，通过受限消息接口请求网络；宿主验证声明域名、协议、超时、响应大小及返回数据结构。用户关闭源、切换歌曲或退出时取消在途请求。源崩溃只影响该源，不影响本地播放器。

先定义 Zenix 自己的完整协议。LX 脚本兼容器作为后续独立模块：它只能补充已有目录结果的音频地址，无法代替本协议的搜索能力，也不能直接在主进程中加载。

## 主程序数据流

1. 搜索窗口读取已启用且支持搜索的源；分别分页请求，保留来源标识，按来源歌曲 ID 去重。跨源同名歌曲先并列展示，不自动合并不同版本。
2. 点击歌曲时，由相应源即时解析播放地址。地址失效后最多刷新一次；失败时显示原始来源和错误，不静默播放相似歌曲。
3. 歌词和封面独立请求、独立缓存；缺失不阻止播放。
4. 喜欢、收藏、历史及播放队列保存来源 ID 和元数据。源停用或卸载后仍保留这些记录，重新启用同一来源 ID 后可恢复解析。

## 下载阶段

下载管理器在主进程维护持久化任务：`queued → resolving → downloading → paused/completed/failed`。任务键为 `sourceId:remoteId:quality`，限制并发数，下载到 `.part` 文件；有条件时使用 HTTP Range 续传，完成后校验大小与音频格式，再原子改名并登记到本地曲库。过期地址由同一源重新解析，不把旧 URL 长期保存。重启后运行中的任务转为暂停，用户可继续或取消。

用户在设置中选择下载目录、默认音质和并发数。搜索结果、当前播放歌曲及歌曲菜单只对支持 `resolveDownload` 的源显示下载操作。已下载文件优先离线播放，同时保留原歌曲 ID，使喜欢、收藏和听歌历史不因本地副本而重复。歌词文件与封面写入可以作为完成下载后的可选步骤。

## 实施顺序与验收点

1. **已完成：移除旧测试源。** 移除旧服务、IPC、依赖和搜索入口；本地搜索继续可用。
2. **源宿主。** 实现清单导入、隔离运行、网络权限、启停和状态展示；提供仅用于开发的自制示例源，不预装真实平台脚本。
3. **搜索与播放。** 将自定义源结果接入现有搜索条和播放器，完成地址刷新、歌词、封面及错误提示。
4. **下载与离线。** 接入任务持久化、暂停续传、下载列表和本地曲库关联。
5. **兼容与迁移。** 按来源 ID 处理旧在线记录；如需要导入 LX 脚本，再单独实现受限兼容层。

每阶段都需要在桌面窗口中实际检查：无源时只显示本地歌曲，有源时搜索和播放可用，停用源后不再发起请求，下载完成后断网仍可播放。
