# v1.0.0 r18 移动界面修补

本轮保持公共版本 1.0.0，Windows 内部 build 与 Android versionCode 为 18，正式发行包含此前 build 16 / 17 的歌单交换、LAN 迁移、统计回忆、睡眠定时器、小组件，以及播放与缓存优化。

## 页面与搜索

页面在同一布局位置连续交叉淡入淡出，内容轻位移，避免等待旧页面完全消失的空档。音乐空间的固定画布没有位移祖先；导航、底部播放控制与原生播放保持独立。系统减少动态效果时停用过渡。

搜索输入、提交与关闭各占独立区域，按钮为 44px 触控区域；音源选择可横向滚动。提交搜索先收起输入法，搜索结果以列表显示：封面、歌名、歌手 / 专辑、播放和更多操作。长标题省略、结果总数及空状态明确，列表滚动不被底部播放条遮挡。点击信息打开快捷操作，独立播放按钮才播放；长按可快捷保存。320 / 360 / 390 / 430 宽度及模拟键盘视口纳入界面验证。

## 弹窗与通知

移除音乐源、删除歌单、清理缓存、安装更新确认改为自绘 28px 圆角玻璃弹窗：半透明渐变、背景模糊、遮罩和短入场动画。使用 HTML dialog 顶层与焦点约束；默认聚焦取消，返回 / Escape / 外部区域关闭，取消不执行操作。更新提醒同样采用玻璃卡片，保留“同公开版本关闭后不重复提醒”的既有规则。提示通知及底部操作面板统一玻璃样式。

Android 的系统权限、文件选择器和系统安装器由操作系统绘制，继续保留系统界面；应用自己的确认与提示使用上述样式。

## 音乐空间

聚焦与放大状态分开保存。单击或双击贴纸只聚焦，不切歌、不暂停、不改变任何贴纸尺寸。长按只打开快捷操作。点击“播放”才调用播放，当前歌曲的暂停 / 继续也必须点击明确按钮。点击“放大贴纸”才展开拼贴布局，点击“缩小贴纸”还原；当前歌曲展开后可通过“打开完整播放器”按钮进入全屏播放器。

窄贴纸只显示更多、放大和播放三个操作，放大后显示喜欢、收藏、歌单等操作。播放状态变化不会自动放大贴纸。

## 验证与限制

真实 Electron 中运行生产 React 移动界面，原生桥使用隔离的合成资料。验证点击 / 双击 / 长按保持原播放和尺寸、显式播放 / 放大、取消确认无删除、确认只执行一次、搜索表单及长标题适配、模拟输入法视口，以及更新安装确认。沿用播放隔离、缓存边界与歌单交换 JVM 合约验证。

具体测试 / 构建 / 正式发行签名与远程工件结果登记在 PROJECT_STATE.md 与 v1.0.0 发行说明。没有连接 Android 真机；桌面浏览器的模拟键盘与指针事件不替代真实输入法、触摸、锁屏 / 省电、后台或离线声音输出验收。
