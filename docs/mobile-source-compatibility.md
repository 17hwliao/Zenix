# 2026-10-15：Android 同源播放失败对照与本地修复

本轮针对移动端无法播放开展实机诊断，没有扩展为更新、界面性能或其他设备的全量验收。GitHub 发布与通道仍为 r39；修复源码和原签名 r40 APK 留在本地，手机已覆盖安装该本地版本。

## 已复现的差异

对照的七份 PC / Android 源脚本 SHA256 一致。PC 使用隔离的生产 SourceManager / SourceRunner，按手机同一首歌的信息、相同 HTTP 授权和域名范围重放，没有修改桌面原配置。隔离环境不能直接解密另一资料目录的系统加密配置，因此本轮没有将解密失败认定为用户资料损坏，也没有覆盖或迁移该配置。

1. Android 为目录适配提供全局 PortableBuffer，但缺少 `isBuffer`。真实源脚本检查 JSON 响应时调用 `Buffer.isBuffer`，立即异常；PC 的脚本环境没有触发该缺失方法。r39 真机已复现该报错，临时只补方法后能够解析出音频地址。现补齐该方法，JSON 对象仍不被当作二进制。
2. 手机 VPN 将音频域名解析为 `198.18.*` Fake-IP。原策略正确拒绝保留地址，但没有获得真实公网地址的兼容路径。实机同一域名的非 VPN 实际网络解析为公网地址；没有关闭 VPN 或修改其配置。仅当系统答复全部为 `198.18.0.0/15` 且活动网络确为 VPN 时，改向系统已验证的实际网络查询真实地址。查询仍在原有有界 DNS 线程池和超时内。

连接时使用经过原地址策略逐一验证的真实公网 IP，仍保留原 URL / Host、TLS 证书和主机名验证，以及 HTTP 授权、域名约束、逐跳重定向和敏感头清除。没有把 Fake-IP 加入允许地址，没有绑定进程或套接字到其他网络；实际连接继续由系统路由。该兼容行为会向实际网络发送对应域名的 DNS 查询，未引入额外 DNS 服务。

只有 Fake-IP-only 情况才允许尝试上述解析。普通私网 / 回环地址、空答复及公网与保留地址混合答复仍拒绝；真实网络答复若含私网、Fake-IP 或其他保留地址，同样拒绝。新增的 ACCESS_NETWORK_STATE 是读取网络状态的普通权限，不修改网络设置。可信更新继续使用独立 UpdateHttp，不复用此音乐源解析逻辑。

## 已取得的证据与边界

- 补丁前的真机源诊断分别复现缺失 Buffer 方法和 Fake-IP 拦截；临时单变量 Buffer 补丁使失败前进到 DNS 环节。
- 原签名本地 r40 使用未经注入的正式生产实现，源解析后实际收到 HTTP 206、audio/mpeg 音频。Media3 真实播放状态为 true，进度由 0 推进至 1.378 秒，使用高品质资源。本次播放的是手机当时选中的《你不知道的事》en 版本，没有将其写成其他歌手的版本或另一首歌已经实测。
- PC 重放中另有源返回 404、503、域名失效或平台不支持。这些外部失败与上述 Android 缺陷分开记录，不能承诺每个第三方源、每首歌始终可用。
- 25 项移动界面 / 源队列 / 地址安全回归及 5 项更新传输 / 发行契约检查通过。新增生产 host 的 Buffer 用例和生产 DNS 选择策略用例覆盖普通公网不回退、Fake-IP 回退必须为公网、私网 / 混合答复拒绝；原 18 项地址边界继续通过。
- Web、Release 和独立验收辅助包构建通过。r40 的原证书、包名、版本、更新公钥 / 固定入口，以及从手机拉取的实际已安装 APK 字节均核对通过。源、名片与外观配置摘要一致；本轮没有卸载应用或清空资料。
- 仅验证一次短时实际播放，不代表长时间播放、全部格式、全部源、两首原始歌曲版本或完整应用内升级均完成验收。测试结束恢复普通 MainActivity，沿用原先暂停意图，不继续主动安排用户测试。

诊断明细、选中歌曲元数据、配置摘要和 APK 工件只保存到本机忽略的 release 目录，不作为源包或仓库资料上传。
