# Android 按状态推进的播放与重试逻辑

2026-10-17，按用户最新要求修订。本地 r45 取代此前 r43/r44 的时间预算方案；旧的整轮180秒、单源45秒、连续缓冲45秒和超时看门狗已删除。旧诊断回执保留为历史，不能据其描述当前行为。

## 正常调用链

`明确点击播放 → 检查缓存 → 选取支持当前目录的源 → 脚本解析地址 → 校验地址与权限 → 连接音频 → 缓冲/解码 → 实际播放`

搜索目录与音频源不同：目录能搜到歌名、封面和歌曲ID，不代表音源能提供音频。LX源脚本在受限WebView运行，原生网络执行HTTP，Media3负责解码和缓存。播放、目录搜索、封面歌词的工作通道相互隔离；点击贴纸聚焦或切换页面不会停止播放解析。

## 以实际结果推进，不按等待时长判失败

| 当前状态 | 处理规则 |
| --- | --- |
| 缓存可完整读取 | 优先使用；部分缓存仍可能需要联网 |
| 源正在初始化或解析，尚无结果 | 保持等待，不因累计时间长切源，不假造进度百分比 |
| 已取得地址 | 完成网络权限检查后立即转入音频连接，不重新搜索歌曲，也不受上一阶段耗时影响 |
| 已连接、正在收数据或缓冲 | 保留当前加载器、连接和缓存；总耗时长不是中止理由 |
| 缓冲就绪/实际播放 | 继续播放；成功解析地址与实际起播分别记录 |
| 请求、源脚本或解码器明确报告错误 | 按错误类型决定重试、换品质或换源 |
| 用户停止、暂停或换歌 | 取消所属解析、HTTP和加载器；过期结果不能把旧歌重新播出来 |

源脚本没有报告进度时，应用只能知道“请求尚未完成”，不能证明它卡死。默认继续等待，用户可以停止、重新播放或到源管理中选择其他源；不把某个等待秒数当作失败。界面以当前阶段说明为主，耗时只保留为诊断信息。

## 明确错误后的回退

1. **连接重置、意外断开、网络返回超时、502/503/504**：同一源/品质额外重试一次。再次明确失败后换源，不因为一次慢响应就换。
2. **资源/品质不可用**：尝试该源声明支持的下一档品质。高品质优先是320k→128k→FLAC；无损优先是FLAC→320k→128k。
3. **404、403、地址权限拒绝**：不对同一请求做瞬时重试。资源错误按品质/源回退；安全校验不放宽。
4. **地址已返回，但音频连接或解码失败**：回到尚未尝试过的源/品质组合，不无限重复同一失败组合。
5. **实际播放后断流**：保存当前位置，新建恢复尝试集合，允许刷新此前成功源的地址；同一次恢复中再次报错不会清空集合、无限重试。
6. **所有候选都明确失败或不支持**：停止并显示失败；用户点重试才新建一次请求。某个候选仍未返回结果，不被伪装成“所有源失败”。

已收到有效地址后不会被此前的解析耗时取消；正在接收音频时也没有整轮/读取倒计时。Media3额外的应用级加载重试继续关闭，明确错误交由上述源回退统一处理。

## 保留的顺序、缓存与网络边界

- 关闭流畅优先时遵守手动源顺序；开启时健康、近期实际成功的源在前，失败源暂时后置兜底。健康排序的冷却期只影响优先级，不终止在途任务、不删除兼容源。
- 同平台LX源复用原歌曲ID；需要匹配其他源协议时核对标题、歌手、专辑与时长，不用同名曲随意替换录音。
- 完整缓存可离线；部分缓存续读仍需原资源有效。新缓存键绑定源与音频地址摘要，避免跨源拼接片段；不清空原有用户缓存，HLS不宣称整首离线。
- 播放专用ScriptEngine等待初始化/调用结果时不设绝对截止；播放HTTP调用和读取不设累计或读取超时。停止/换歌通过关闭对应引擎与Call主动取消，线程和请求队列仍有数量上限。
- DNS查询及尚未建立连接的网络探测保留原有基础连接失败判定；TLS、域名、私网限制、重定向和响应大小校验保留。这些真实错误可能触发回退，不能因“状态推进”忽略安全或伪称网络成功。第三方脚本自身返回错误仍按实际结果处理。
- 搜索/元数据的独立请求预算保留；可信软件更新入口、签名和网络实现未改。

## 验证边界

JVM用当前生产源调度验证：模拟解析五分钟后成功仍被接受、时间本身不触发回退、明确错误最多额外重试一次、所有候选按失败结果逐项耗尽、取消后迟到结果丢弃、冷却源不被平台筛选误删，以及缓存隔离。生产错误/恢复回调原样提取执行，验证只有错误进入回退、播放中断保留位置和用户暂停后的迟到错误不重新播放。

本地 r45 已执行真机辅助模式 `playbackStateCheck`：实际播放客户端调用/读取倒计时为0；受控源脚本等待显式结果并支持取消；Media3等待首字节的3秒采样期间没有自行停止；用户停止后真实源重新起播，进度从0.065秒增长到5.115秒。三秒真机采样不等于五分钟真机等待，五分钟场景由上述模拟测试覆盖。正式签名和已安装APK摘要核对一致，音乐源/配置摘要保持一致。系统媒体音量为0，未更改，不声称扬声器有声验收。
