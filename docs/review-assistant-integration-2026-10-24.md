# 星音集成全量改动 Review 与修复记录

范围：对照 main/r55，覆盖待发行角色、皮肤、语音、资料查询/修改、五句悬浮歌词与纯净模式，以及本轮固定指令接线；检查双端宿主、IPC/原生权限、存储、取消生命周期和相关播放/缓存/协作/更新契约。本记录不声称逐行审计所有未变更依赖或证明所有设备行为。

## 可确认问题及修复

| 优先级 | 触发与影响 | 修正与证据 |
| --- | --- | --- |
| P1 | “歌词提前半秒”先进入宽泛歌词查询，无法校正 | 固定控制指令先于资料查询；覆盖全部 25 个不同示例及低置信度确认 |
| P1 | 独立任务/更新操作统一读取个人资料，资料不可读会误挡更新与导航 | 仅需要歌曲对象的动作读取 snapshot；模拟资料读取失败，检查更新/任务/定时/空间仍可执行 |
| P1 | 打开任务/设备协作面板后，通用导航完成事件立即将它关闭 | 面板入口不发送关闭工作台事件，增加行为回归 |
| P2 | 在喜欢等前台集合请求缓存，会回退选择另一张正在播放的歌单 | 明确前台上下文优先；非自定义集合不猜测其他歌单，缓存前显示固定目标 |
| P2 | 换装图集异步解码晚于恢复默认返回，可覆盖用户后续选择 | 预留选择修订并在解码后检查，有新选择则丢弃旧结果 |
| P2 | 助手当前句查询未使用既有歌词偏移，可能与界面不同步 | 沿用同录音的偏移；新增提前半秒跨句验证 |
| P2 | 旧助手纯净模式请求可在手动离开、重入页面时再次生效 | 手动进入/退出时清理请求，实际双端组件验证打开与恢复且未发播放命令 |

检查的保留行为：歌单批量喜欢/收藏幂等保存；移出前确认、歌单变化时中止；不删除音频/其他歌单；取消隔离迟到识别、歌词和任务结果；手动切歌不被旧接力回执暂停；临时轻音乐探索不改长期偏好；皮肤只接受受限图片与配置，保留 Zenix 标识；原签名、包名、资料根目录、升级公钥与 NSIS 兼容分支未更换。

打包核对另发现八套服装图集同时进入 renderer 与 Electron 原始资源。原生桌宠只需要默认星音帧，Windows 原始资源白名单收窄为 zenix-muse*.png；服装仍由 renderer 选择后保存，避免重复打包图集。

## 测试夹具修复

旧 Vite 测试的 port:0 实际回退到默认端口，受现有开发窗口占用影响，且启动失败留下资源。桌面 UI 与首次音源设置夹具改用 middleware+系统临时端口，保留全部原断言。封面夹具在关闭自己的服务并等待写入后再删除自己的临时目录，Windows 清理允许有限重试。手机入口新增断言执行完恢复首页，避免污染同一脚本后续场景。没有通过关闭用户窗口或削弱产品断言换取通过。
