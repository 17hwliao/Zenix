# 2026-10-18 自动播放规则调整（本地实现完成）

以下规则取代本文旧版的自动匹配策略；原严格匹配规则仅用于折叠的手动检查工具。

- PC 和 Android 播放某张自定义歌单时，可在当前播放队列直接开启自动平替；管理页保留同一开关。开关按歌单保存，搜索、历史、收藏等没有该歌单上下文的播放不会套用它。
- 已有完整原曲缓存或已保存的替代关联优先复用。需要新匹配时，直接以歌曲标题搜索已启用且支持播放的源，按源/搜索结果顺序取前三个有效去重结果，不再先等待原曲解析失败，也不以歌手、专辑或时长差异要求人工确认。不会预先联网扫描整张歌单；队列走到哪首便自动处理哪首。
- 候选解析和音频响应探测共用每首每轮最多三次额度；真正播放/解码明确失败后，继续剩余候选。成功便播放当前歌曲，歌曲结束后遵循队列设置继续；三个都失败或没有候选则跳过该歌，整轮剩余队列均失败后停止，防止循环模式无限重试。
- 取消、暂停、切歌会取消当前任务，不接受迟到结果；正在等待的第三次被取消后不会重置额度。只有已经明确结束的失败轮，在以后重新发起播放时才可建立新一轮。解析/探测/缓冲不按累计时间强制取消。
- 原歌曲身份、歌单顺序和用户资料保留，替代关联仍可撤销。高级手动工具保留，但自动模式无需勾选、扫描、选版本或逐首维护。
- 移动端修复同一歌曲管理行不执行播放、贴纸忽略所属歌单上下文的问题；队列/下一首插入保留所属歌单，避免平替开关失效。正在加载/失败时改变开关会重建当前播放请求；正常播放中的歌曲不因开关变化被打断。
- 桌面顶部拖动区放在页面覆盖层之外，首页/音乐空间居中搜索框以上与两侧分区拖动，歌单管理/搜索/设置/队列中保持顶部拖动；窗口按钮不参与拖动。
- 错误提示补齐关闭按钮、长文本换行和独立滚动，诊断展开不把关闭按钮挤到视口外。关闭只隐藏本次错误，不取消播放、重试或关闭更新功能；普通移动提示不阻挡下方歌曲手势。

本次不变更已发布版本、签名、更新通道或 Windows 安装器。未操作用户手机、未执行真实音源逐曲试听或系统升级。

# 歌单平台平替：本地实现与验证

2026-10-17。按用户批准的方案实现，范围为 Windows PC 和 Android。保留已有本地状态驱动播放修复，并按用户补充要求纳入 Windows 安装器卡住修复。本轮未提交、推送、创建 PR、打包发行或切换更新通道。

## 先修正导入播放链路

导入歌曲保留原平台目录 ID，`lx.playlist:catalog` 是元数据身份，并非真实音频服务。QQ 的歌单元数据补齐与搜索目录一致的 albumId/albumMid。Android 原先提前过滤不支持原平台的 LX 源，导致其他目录的同录音匹配无法执行；现在同平台可直接复用 ID 的源优先，其他源仍能进入严格的歌名、歌手、专辑和时长匹配。严格匹配不放宽为同名翻唱或任意录音。

## 使用入口和保存方式

两端歌单管理页均有“平台平替”：按歌单保存的自动开关、扫描/继续、处理选中、单曲重新匹配、版本确认、恢复原曲和全部恢复。失败提示可进入该歌曲所属歌单。原曲信息、ID 和顺序始终保留；替代关联独立保存在原歌曲的 replacement 字段，播放队列携带 playlistId 确定所属歌单，避免同一歌曲在不同歌单之间串用开关。收藏/历史不保存此临时队列上下文。

关联只保存目标目录身份、歌曲元数据、状态、候选及已用次数，不保存临时音频地址、请求头或嵌套替代链。单曲写入核验歌单快照与前一次关联状态，拒绝过期任务覆盖新选择；旧资料没有新字段时按原结构读取。完整缓存优先识别，不把本地缓存误当网络失败。

## 匹配与三次额度

- 先搜索同名、同歌手、同版本的录音；支持标点/空格和多人歌手分隔符规范化。时长未知、超过3秒差异或专辑明显不同均进入人工选择；Live/翻唱/伴奏/Remix 等版本差异不能自动替换。不同歌手的同名歌曲不自动匹配。
- 每首每轮最多三轮检索词，每个已启用且支持搜索与播放的源仅取首批结果，候选去重排序后最多保留12项。检索元数据本身不占三次音频尝试额度；没有结果也不会无限分页。
- 每轮最多三次候选解析及音频响应验证。发起前持久化占用次数；失败、跳过或取消不返还已占额度。平替内不再套品质轮询/瞬时额外重试，Windows 平替媒体会话也不私自刷新过期地址来绕过计数。
- 解析、接收及缓冲仍在等待时不因累计时长取消。用户可跳过当前候选或取消任务；跳过保留已用次数并继续，取消/离开页面丢弃迟到结果。正在等待原曲检查时点跳过，会进入平替查找。
- 播放器明确报告目标音频失败后，自动开关允许时继续本轮剩余额度。次数耗尽停止；“重新匹配”是显式新一轮。已经实际成功的关联以后重新起播时可以建立新的恢复轮；普通暂停/继续和切页不自动清零未完成轮次。

完整缓存检查、候选解析和音频探测均不输出声音。HTTP 成功和可识别音频头只标记“待播放验证”；实际播放器开始播放后才改成“播放验证通过”。候选扫描使用 Android 独立线程和脚本/目录通道，不停止当前播放。取消令牌、代次检查及有界取消记录防止跨任务取消和迟到提交。

DNS/建连基础错误、TLS、域名/私网限制、HTTP 许可、响应大小与重定向校验保留。状态驱动不表示忽略安全、伪造进度或承诺上游一定返回。更新模块、分发配置、公钥和签名清单没有改动。
