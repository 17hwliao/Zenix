# v1.1.0 / r55 功能迭代与审查

本轮整合用户批准的 24 项方向，沿用原播放器、私人资料、音乐源与更新通道。PC 和 Android 在“音乐工作台”提供六组入口；音乐空间继续使用原贴纸画布，浏览与聚焦不会触发播放。

## 可用功能

| 方向 | 本版实现 |
| --- | --- |
| 空间与漫游（1、2、14、15、16、22） | 空间书签、镜头恢复、分区与拖入整理；指定漫游范围、探索倾向、近期歌手避让；歌曲/歌手减少出现、版本排除及撤销；临时岔路与返回；完整、轻量、减少动效。 |
| 私人资料（3、4、12、23） | 当前实际录音的时间书签与备注；本机保存歌词和私人内容检索；歌单修改记录及带冲突核对的撤销；备份预览、选择恢复、功能设置备份、中断恢复与保留当前资料。 |
| 缓存与任务（5、6、7、20） | 离线准备、按场景固定完整缓存、暂停/继续/取消及失败项重试；音频/歌词/封面/后台准备分别设置联网偏好；后台导入和批量处理，解析结果先预览再确认。 |
| 播放与版本（9、10、11、17、18、19） | 短片段试听及恢复原队列/进度；版本偏好记忆；A–B、歌词范围循环和速度；原地恢复；读取真实源诊断与平替过程。仍为每轮最多三个候选，按状态等待。 |
| 设备协作（8、13、21） | 复用原局域网配对；播放接力、批准后排下一首、选择同步歌单/喜欢/收藏/偏好。各类权限独立；接收成功后原设备才暂停，部分同步有明确结果。 |
| 音乐助手（24） | 原创 Q 版形象、登记功能的文字指令与快捷操作；透明 PNG/声明配置皮肤、模板与本地预览；独立 PC 桌宠、Android 可选悬浮；状态动作、播放律动与减少动效。 |

界面入口：电脑“播放器设置 → 播放与声音 → 音乐工作台”；手机设置及音乐空间工具栏。空间书签/分区需要先打开实际音乐空间。

## 本轮审查与修复

审查覆盖新增共享规则、界面、Electron 服务、Android 服务，以及受影响的播放、解析、缓存、资料、局域网、备份和发行调用链。重点修正：

- 离线解析占用播放任务通道；固定缓存满时误伤播放；缓存提交/清理竞态和不同录音别名串用。
- 试听、书签、歌词读取的迟到结果影响新选择；当前录音身份和时长与导入原曲混用。
- 结构化音乐目录 ID 被截断；取消后后台写回；接力确认错误暂停新歌曲。
- 同步中途失败却不说明部分已完成；重复同步使用 toggle 误删已有喜欢/收藏。
- 备份中断恢复自动覆盖新资料；回执/修订过期、冲突撤销和网络策略恢复并发。
- 后台歌单确认失败丢失预览 token；界面关闭重开丢锁；工作台模块加载失败时关闭按钮无法点击。
- Android 网络策略检查复制整张任务表；改为只读取必要的小范围资料。

更新网络与用户音源/联网偏好保持独立。没有更换资料目录、Android 包名/密钥、更新公钥或历史下载地址。功能设置增加为旧备份格式的可选扩展，旧备份仍可读取。

## 验证及边界

- 完整本地回归：**269/269**，失败 0、跳过 0，包含真实生产 Java 方法/JVM 网络、NSIS 安装器隔离回归、真实 Electron 加密与 UI。
- 双端 UI：隔离 Electron 中运行真实 React，桌面桥接及模拟 Android 原生桥接，1000/390/320px 遍历六页签；覆盖焦点、关闭、模块/资料失败恢复及不创建额外移动播放器。
- TypeScript、桌面 Web、Android Web、Android Release、Windows NSIS 构建通过。
- 实际 APK 原证书与既有 r54 比对通过；Windows 安装器实际包内版本为 1.1.0/r55，58 个打包核心 CJS 与本地源码一致。内置更新配置、公钥及资料身份保持一致。
- 已发行 Windows r28 安装器按 GitHub 原工件摘要确认后，执行其真实更新校验代码：stable/preview 均接受本次原密钥签名清单并识别 r55。此项为清单兼容验证，不等同于远程下载或系统安装。

用户已确认前阶段完成，后续用户层面测试按约定跳过。本轮未操作用户客户端/手机，不将历史实机通过或本地编译当作本工件的双端实机升级证据。跨设备真实接力、外部语音识别服务、系统悬浮权限和真机帧率不在本轮已证明范围。

语音唤醒仍按设计属于后续阶段，没有常驻监听占位开关。PC 按键说话取决于系统 Web Speech；不可用时使用文字。Android 系统识别依赖设备服务；应用外角色采用原生待机形象，完整状态动作在应用内。离开页面不结束明确后台任务；关闭应用会结束尚未完成的界面导入，持久化离线任务可继续。版本/数量约束及各组证据见 docs/design 下对应集成文档。

构建工具仍提示入口 chunk 较大及 Gradle 旧 API 警告，本版没有为了消除提示放宽检查或改动整个依赖树。
