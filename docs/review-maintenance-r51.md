# v1.0.4 / r51：音乐源首次使用与搜索恢复

## 交付设计

- 新装软件不预装或自动运行第三方脚本。用户添加可信脚本后，源页面明确区分初始化、搜索、取得音频地址和真正开始播放。
- 新添加的兼容脚本在其声明支持的平台中依次优先选择 QQ、酷我、酷狗、网易云、咪咕。这是默认建议，不代表服务健康检查。已经安装的音源与搜索选择不自动迁移；重新获取脚本也保留旧的有效默认选择。
- PC 与 Android 共用“先搜索，再试听”引导，支持选择音源、保存搜索平台和打开试听搜索。搜索本身不切歌，仍由用户点击歌曲的播放按钮；不会绕过正常播放、取消、缓存和品质回退链路。
- 网易云业务错误与异常成功响应显式报错，保留真正空结果。失败后可再次提交同一关键词；更换平台后旧平台结果不能继续冒充新平台结果。
- PC 快捷获取脚本改为预览后确认，确认页说明新兼容脚本的 HTTP 权限，支持调整。更新与批量导入保留已有音源的 HTTPS-only / 域名限制，不修改全局安全策略。更新下载与音乐源授权继续独立。
- 播放诊断展示未验证、仅取得地址、近期实际播放成功三种状态。固定的“当前环境已验证可播放”推荐文案删除；缓存播放不当作音源验证成功。

## 审查与修复

本轮审查覆盖此次全部暂存前改动及调用方，并核对搜索、播放与自动平替、取消、缓存、源配置读写、分享包、移动桥接、更新校验与 Windows 安装兼容等关键链路。未改动贴纸布局、平替三候选额度、播放状态等待、更新信任身份和安装器。

发现并修复：

1. 新装平台直接取脚本键顺序，可能再次选到限流的网易云。改为确定性的支持平台优先级。
2. 旧默认平台未写入显式设置时，重新获取脚本可能被新的默认值改变。更新前读取有效旧值，平台仍支持时保留，且不清空其余设置。
3. 引导初次收到异步源列表时，选择控件可能短暂显示第一个选项。草稿绑定源身份和当前持久化值，避免错显或提交错误选择。
4. 保存平台不改变原搜索会话键，相同关键词可能沿用旧平台结果。搜索会话键加入非敏感的当前平台标识，不把私有源设置暴露给搜索 UI。
5. 同词再次提交只设置相同字符串，不产生新请求。显式提交递增搜索轮次，重试重新发起请求；旧响应仍受代次和取消保护。
6. 快捷添加绕过预览，并且源添加与播放成功混为一谈。改为确认后添加，分别展示实际阶段与后续操作。
