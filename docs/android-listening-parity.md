# Android 本轮功能适配

本文件记录 2026-10-17 的本地源码状态。没有生成新安装包或发布；不能据此认为用户手机已安装这些功能或已完成真机验收。iOS 发行继续暂停，本轮移动端实现目标为 Android。

## 设置与操作入口

Android 设置分为播放、歌词、外观、资料与更新、设备连接、歌手与专辑。分类使用三列两行的大按钮；搜索框占完整一行，支持设置名称与常用关键词，结果优先匹配标题。点击结果定位并短暂高亮，歌词校正和 EQ 可展开到相关控制。搜索只查本地设置索引，不请求网络；搜索期间保留当前分类的编辑状态，不列出 Windows 专属能力。

音质、缓存容量、悬浮歌词字体与布局、歌词字重、批量歌单目标使用统一的圆角深色选择菜单，自动按可用空间向上 / 向下展开并在菜单内滚动。设置卡片和展开栏统一留白，不为新版卡片增加全屏模糊或贴纸空间布局重构。

## 功能对应关系

| 已批准功能 | Android 实现与入口 |
| --- | --- |
| 播放状态与后台控制 | 原生 Media3 播放与媒体通知；解析阶段展示歌曲身份、播放阶段交回媒体通知。支持通知栏 / 锁屏 / 耳机媒体控制。厂商通知栏呈现仍需真实设备观察，编译不等于实机通过。 |
| 搜索建议与历史 | 歌曲搜索的本地建议、最近提交记录与清空。设置搜索是另一个入口，不修改歌曲搜索或队列。 |
| 队列操作 | 播放列表的独立整理入口提供上下移动、批量移出和撤销；歌曲长按提供下一首播放、加入队列。移动端使用触摸按钮，不要求鼠标拖放。 |
| 歌词设置与校正 | 详情播放器就近入口；设置的歌词分类也可校正当前歌曲时间并调整字号、行距、字重、翻译与突出显示。悬浮歌词保留授权、字体、颜色与布局设置；原生时间校正接入同一歌曲身份。 |
| 批量歌单 | 歌单管理提供选择、复制、移动、排序、移出和重复候选核对；资料保存和过期快照检查由原生实现。 |
| 分类与设置搜索 | 六分类、设置搜索、结果定位、圆角选择菜单与展开栏。 |
| 手机遥控 PC | 在 Android 应用内部输入地址和配对码、等待电脑确认、查看歌曲、播放 / 暂停、上下首、进度、电脑音量、刷新与断开。手机本地队列不被遥控替换。 |
| PC 输出设备选择的移动对应 | Android 耳机 / 蓝牙 / 扬声器路由交由系统管理；设备分类提供打开系统声音设置的入口。没有用通话音频路由冒充媒体输出切换。 |
| 自定义快捷键的移动对应 | Windows 的应用内 / 全局组合键保留为桌面专属配置。Android 使用通知栏、锁屏和系统媒体按键；不显示无法注册的桌面快捷键表单。 |
| EQ 与预设 | 通过真实播放器音频会话应用 Android Equalizer，提供预设和自定义频段；未获得音频会话时说明等待应用，不把界面保存当作已经生效。 |
| 音乐小窗的移动对应 | Android 系统桌面音乐组件，以及已有悬浮歌词；保留 3×3 等组件尺寸的请求入口。Windows 的置顶窗口和贴边行为属于桌面窗口系统。 |
| 歌手与专辑 | 设置及当前歌曲就近入口，浏览已收录曲库、收藏与播放记录。与 PC 一样，不宣称是歌手的完整在线作品。 |
| 平台歌单迁移 | 共用 QQ / 网易云 / 酷我解析、分页和预览；Android 原生传输限制官方域名及公网 DNS，确认后保存，部分结果需额外确认。 |
| 分享、统计和定时 | 保留歌单文件 / 局域网迁移、音乐源分享包、统计与回忆卡、定时停止播放等既有 Android 实现。 |

## 应用内遥控的边界

原生 `RemoteClient` 使用独立的有界执行队列，只有用户提供的 RFC1918 IPv4 和端口可连接，不解析任意主机名，不跟随重定向。请求和响应有超时及大小限制，不能从此入口调用音乐源或更新接口；没有改动更新网络、发行身份或版本号。

电脑仍验证六位配对码并明确允许。会话令牌仅保留于原生内存，不保存到资料，也不返回网页 UI；读取状态只返回筛选后的歌曲与播放字段。切换设置分类或页面时尝试断开；应用在后台时暂停轮询，连续网络失败停止自动轮询并提供手动刷新。电脑可以拒绝 / 撤销连接或关闭整个服务。强制终止应用或网络中断时无法保证断开请求送达，电脑端可撤销，服务本身也有时限。这里不进行音频投送。

## 必要检查

原生 Android 客户端逻辑在 JVM 上实际连接本机的生产 Electron 遥控 HTTP 服务，验证配对、确认后控制、撤销拒绝、不泄露令牌、非法地址与参数拒绝以及拒绝重定向。它验证实际 HTTP 及 Java 客户端逻辑，不代替 Android 系统网络或两台实体设备验收。

移动 React / Chromium 回归覆盖应用内配对 / 等待 / 控制 / 断开且手机本地播放不变、设置搜索和歌词定位、不能搜索到桌面全局快捷键、320 / 390 / 430 窄屏布局，以及既有歌单链接导入与贴纸 / 播放器流程。界面请求使用隔离的原生替身，和 JVM 的真实 HTTP 用例分别记录。已查看遥控与设置搜索截图。TypeScript、两端前端构建与 Android Java 编译单独检查；没有把这些结果写成手机实测。
