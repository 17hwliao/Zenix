# 星音固定功能指令集成

本轮目标版本 1.2.0 / r56。使用本地固定指令与原有查询解析，不接通用大模型、不引入自主任务规划。角色、文字与按住说话共用执行入口；皮肤只呈现动作。更新身份、密钥、资料根目录与三候选平替规则保留。

## 可用指令

| 类别 | 示例及实际行为 |
| --- | --- |
| 播放 | 暂停、下一首沿原播放器；单曲循环同时关闭随机；音量调低一点降低 10 个百分点、最低为零 |
| 搜索查询 | 找一下王菲的《红豆》打开候选搜索，不擅自播放第一项；歌手、前面第三首专辑等沿相邻十首内查询 |
| 歌词 | 打开纯净歌词进入当前歌曲详情且不切歌；歌词提前半秒按当前歌曲 ID 累计偏移、限制 ±30 秒；关闭悬浮歌词不影响主界面歌词 |
| 缓存 | 缓存这张歌单先显示名称、数量，确认后使用原离线任务；只用缓存播放先确认并关闭音频、歌词、封面、预加载四类后续联网；更新和局域网独立。既有播放连接不等同于已经终止，任务中心可查看实际状态 |
| 任务 | 看看现在有什么网络任务展示后台离线任务和状态，同时打开任务中心；不是系统全进程流量监控 |
| 空间 | 返回我的空间保持浏览来源；打开夜间分区要求唯一同名分区，仍按当前空间歌曲过滤；保存当前空间位置要求音乐空间已打开，保留镜头、缩放、焦点与安全歌曲引用 |
| 漫游 | 少听这种确认后减少当前歌曲，不冒称识别曲风或排除整类；暂时听一些轻音乐须已开始漫游，用关键词轻音乐临时探索至多三首，下一首生效；回到刚才的漫游恢复原候选路线，不改长期规则 |
| 统计定时 | 看看这周听歌情况统计本地日期周一至今天；半小时后停止播放调用原定时器，到期保留应用和资料，可在工具中取消 |
| 协作 | 把音乐接到电脑上、把这首排到电脑下一首从已配对手机发起；要求对应 handoff/submission 授权，不支持本地音频清单接力，等待电脑确认。接收端未真正准备好不停止手机 |
| 备份更新 | 备份歌单通过系统文件保存导出全部自定义歌单为 .zenixlist，不包含音频；检查更新沿用户当前通道和原有可信更新模块，不自动点击安装 |

PC 空格只在前台非输入控件区域有效；Android 应用内悬浮按钮长按录音、松开提交、上滑取消。语音与文本使用同一识别表；低置信度确认。只允许单步明确操作，不识别的语句不执行。批量保存、网络限制与长期偏好先预览确认；取消后未提交的操作不执行，已提交的保存不能假装撤回。

## 接线与解耦

- controlIntent：固定短句到动作，不执行代码。
- controlCommands：对象核对、确认计划、结果说明；查询和更新不强制读取歌单。
- controlHost：PC / Android 调用现有业务，设备协作使用独立通道。
- controlUi：页面接受请求后才报告已打开；任务面板不发通用关闭事件。
- 原 libraryCommands / libraryHost：保留现有资料确认、范围查询与保存冲突检查。
- 显示请求只改变页面、焦点、纯净模式或分区，不调用播放；隐藏角色不取消音乐任务。

## 本地验证与发布边界

自动检查覆盖列举短句、低置信度/否定、确认前无写入、取消、查询与资料读取隔离、任务面板导航、实际双端纯净歌词入口、歌单与配置保留相关契约。记录实际运行结果于发行说明与 Review 记录。构建成功不等于手机真人语音准确率或完整实机升级验收；不操作在用客户端。原始头像与八套服装仍为 Live2D 风格图像/姿态切换，不是真正 Cubism 模型。
