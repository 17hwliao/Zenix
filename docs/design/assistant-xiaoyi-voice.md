# 星音：晓伊朗读配置

2026-11-06。用户试听后选择②晓伊，随后确认 PC 与 Android 均使用该音色，取消读取手机系统音色，不连接设备。本次只修改本地源码，不打包或上传，不修改公开版本、构建号、签名或更新清单。

- 默认声音固定为 `zh-CN-XiaoyiNeural`，语速 `+0%`、音调 `+0Hz`，保持试听时的参数。中文语音识别、模型理解和朗读分别独立；不需要语音 API Key。
- PC 使用 Electron 主进程的独立 Worker 和锁定的 node-edge-tts 1.2.12，返回内存 MP3，renderer 播放后释放 Blob。终止朗读、切换请求、隐藏应用和退出都会取消所属工作，迟到结果不能重新播放。网络或解码失败回退原系统中文朗读，同一条回复后续分段不反复尝试失败的网络服务。
- Android 使用独立 OkHttp WebSocket 和原生 MediaPlayer 的内存 MediaDataSource，不启动本机服务、不依赖 Python、不经音乐源或更新网络，也不修改系统默认音色。请求文字最多300字，音频最多2 MiB，网络准备最多25秒；该限制只属于助手朗读。失败回退原生系统 TTS，并有30秒失败退避，避免每段都重复等待。
- 停止和销毁会关闭连接、播放器和内存资源；Android 使用 generation 拒绝已经取消的音频与 fallback。只在真实播放完成后返回 spoken=true。系统 fallback 明确返回 voice=system，由界面提示，不能声称系统声音就是晓伊。
- 开启“语音回复”时，回复文本将发送至微软的在线朗读服务，界面已显示此说明；关闭后不生成朗读请求。不开新音色设置页；模型配置、皮肤和歌单均不保存朗读文字或生成音频。
- 这是第三方客户端访问的在线服务，不保证永久免费或一直可用，保留系统朗读回退。PC 依赖与 Android wire-token 兼容适配的 MIT 署名及原文保存在 licenses/node-edge-tts 和 THIRD_PARTY_NOTICES.md。

必要自动检查包括 `Test-AssistantOutputVoice.cjs` 的七项测试：PC 固定音色/严格参数、代理准备期间取消与超时、Worker 终止/迟到音频、renderer 音频释放与系统回退、停止不触发 fallback、生产 Android 网络类的帧校验与取消、Android 系统 TTS 初始化与播放器生命周期。Android wire token 对比上游实现的五个固定时间值；JVM 测试不会连接真实语音服务。

另外保留旧语音按住/松开、早松手、低置信确认、取消及多入口回归。PC 已以固定测试文案真实生成晓伊 MP3；首次网络探测失败后后续生成成功，说明在线服务存在波动，不能据此声称稳定可用。Android 原生编译和受控协议测试不能替代手机实际播放；按用户选择，本轮不安装或操作手机。现有已安装版本不会因工作区改动自动换音色，需后续加载本地新代码或随用户授权的发行更新生效。
