# Zenix 下一轮功能开发

本轮由用户于 2026-10-22 授权开发、五个子任务协作、全量审查及修复、必要测试、双端打包和新版本发布。公开版本暂拟 1.1.0；最终构建号必须在发行盘点后递增确定。本文是计划与验收范围，不是完成声明。

## 共同宗旨

保护现有播放、贴纸空间、用户实际资料与升级链路。共用规则与格式，平台后端分别执行。界面和助手只调用业务接口；只有播放器可以改变实际播放。失败、取消及过期结果不能覆盖当前操作。不得以全局重构、第二份用户资料库或关闭校验实现功能。

## 五个工作组

| 工作组 | 功能 | 文件边界 |
| --- | --- | --- |
| 资料与检索 | 3 书签、4 私人搜索、12 修改撤销、23 备份预览 | personal feature 目录、个人资料/备份实现，其他入口由主任务接线 |
| 播放与版本 | 9 试听、10 版本偏好、11 片段练习、17 原地恢复、18 健康状态、19 平替说明 | playback feature 目录、播放器/版本规则；不修改缓存网络 |
| 缓存与任务 | 5 离线、6 场景缓存、7 网络偏好、20 后台任务 | tasks feature 目录、缓存/离线任务；共享原播放器缓存 |
| 空间与漫游 | 1 空间书签、2 分区、14 漫游控制、15 少听、16 临时探索、22 动效 | space feature 目录、空间/漫游；不接管播放 |
| 跨端与助手 | 8 接力、13 共同排队、21 选择同步、24 桌宠助手 | connection/assistant feature 目录、远程通信/角色；不直接改个人资料 |

运行环境最多允许主任务与三个子任务同时活动；五个子任务分批交错运行。主任务负责公共接口、双端入口、集成、审查与发行。

## 关键行为

- 自动平替每轮至多三个不同候选；按实际状态等待，不以新增总耗时强行跳过；成功依据实际播放。
- 手动切歌、取消与更新选择必须使旧请求失效。试听结束只在用户没有新操作时恢复原上下文。
- 歌单撤销以修订号/差异核对，保护后续及其他对象的新修改。恢复可预览、选择范围，兼容旧资料。
- 缓存完成由真实文件/范围决定；固定缓存不可静默淘汰；离开任务面板不结束任务。
- 浏览、贴纸聚焦、缩放与播放保持独立。视觉隐藏暂停动画，不取消播放和明确后台任务。
- 偏好分长期、会话和临时探索；网络/解析故障不作为负面喜好。
- 接力目标未准备成功不暂停原设备；投稿、同步、播放控制权限分开。
- 皮肤仅外观资源和声明配置，不执行脚本；助手关闭不影响功能。未完成的唤醒能力不得显示成可用。
- 更新网络、签名、发行身份、历史下载工件及用户资料根路径保持既有契约。

## 集成顺序与检查

首先资料/任务基础及公共桥接；然后播放恢复和缓存；再私人内容、空间/漫游；最后跨端和助手。每组用可观察行为测试，合并后审查新增代码及受影响的全项目调用链，修复确定问题并运行必要回归。设备/云服务条件不足时如实记录，不用占位开关或编译成功当作功能完成。

源码/工件/清单发布按本次用户授权执行，但只在相关发行检查成立后切换。此前本地准备中的 r54 元数据属于旧阶段，不能误当成新版本清单一起发布。
