# Zenix v1.0.1 / r38

本修订汇总本轮代码审查、播放修复和移动动画优化；Windows 与 Android 均为 1.0.1 / build 38。

- 移动贴纸切换统一先读取几何、再提交动画；快速连续切换从当前画面继续，过渡完成前保留旧贴纸，减少跳变和重复布局。
- 保留贴纸展开、周围让位及镜头同步效果；聚焦不切歌，播放与全屏仍使用明确按钮。
- 详情进入期间延后封面与歌词请求，暂停底层视觉工作；有效本地封面直接显示，读取失败仅重试一次。
- 修复 PC 等待资源时暂停操作重启解析、移除当前歌曲误恢复播放，以及 Android 移除暂停歌曲的状态问题。
- 备用资源更严格核对歌名、歌手、时长和已知专辑；PC 解析等待总预算 30 秒，各来源最多 10 秒并共享剩余预算。
- Android 播放音质状态与保存设置保持一致；恢复记录涉及的背景文件不被提前清理。
- PC 搜索追加结果保留浏览位置与贴纸焦点。暂停发行的 iOS 仅补充损坏库存保护，没有编译或启用发行。

本轮最终回归 **114 / 114 通过，无跳过**；桌面 Web、Android Web、原签名 Android Release 与 Windows NSIS 安装包构建通过。实际 APK / EXE 中的版本、构建号、更新公钥和固定入口核对通过；APK 使用原正式证书及包名。Windows 沿用签名清单信任，目前没有 Authenticode 发行证书。
