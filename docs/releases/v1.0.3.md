# Zenix v1.0.3 · r46

本版合并 PC 与 Android 的导入歌单播放、平台平替、状态驱动加载和 Windows 升级兼容修复。

- 修复 QQ 等平台导入歌曲的音源选择与跨目录同录音匹配。
- 歌单管理新增平台平替：自动开关、扫描、选中处理、版本确认、跳过、取消和恢复原曲。原曲信息、顺序、喜欢与收藏保留。
- 每首每轮最多尝试三个候选；第三次成功仍可正常播放。已接受候选的播放接续不重复占用新候选，明确失败才使用剩余额度，不进入第四个候选。
- 解析、音频接收和缓冲按实际状态等待，不因累计加载时长强行中断。支持用户主动取消；保留 TLS、网络权限和发行校验。
- 修复取消期间的迟到解析与关联写入，恢复原曲/改选后的缓存身份，以及 Android 队列撤销丢失歌单上下文的问题。
- Windows 安装与卸载使用原生进程检查；补齐旧卸载器 PowerShell 前置流程的兼容处理，保留覆盖升级资料与标准安装流程。

Android 沿用 `com.zenix.musicplayer` 和原正式发行证书；Windows 沿用既有应用身份及签名清单信任方式。本版公开版本 1.0.3，双端内部构建 46。旧正式客户端继续使用原内置 stable/preview 签名清单入口，重新检查更新可获取本版；已有历史工件与下载地址保留。

本轮已完成两轮聚焦 Review、针对性回归及构建校验。按用户约定跳过完成后的额外用户层面测试；未重新验证所有设备的实际播放、全歌单在线资源或真实系统覆盖升级，不把编译、自动测试及上传成功表述为实机通过。第三方音乐源的实际可用性取决于其上游服务。
