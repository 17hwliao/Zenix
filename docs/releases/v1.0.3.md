# Zenix v1.0.3 · Android r48 / Windows r47

Android r48 修复自动平替只绑定搜索结果来源的问题：同一候选现在使用普通播放的音源与音质切换，并验证音频响应；全部可用连接明确失败后才尝试下一候选，每首仍最多三个候选、按状态等待并支持取消。搜索接口全部失败时停止提示，避免把网络错误当成无歌可播。进度展示实际搜索源、返回数量、候选序号与连接状态。Windows 保留 r47，未修改其播放逻辑或工件。

实际 r47 手机对照已证明：同一个候选通过野花失败，普通解析器通过星海可通过音频检查；对齐 PC 配置后原 r47 实际观察到首歌自动平替并起播。本地新 Android 逻辑回归与包身份校验通过，但未新增 r48 系统覆盖安装验收。详细逻辑及边界见[移动播放路径说明](../mobile-playlist-replacement-path.md)。

## r47 维护记录

公开版本保持 1.0.3，双端内部构建由 46 增至 47；旧版使用原有应用内检查更新入口获取维护修订。原 v1.0.3 标签与 r46 工件保留，维护代码随 main 提交并在 GitHub Release 说明中链接。

- 歌单播放时自动按歌名搜索前三个去重结果并依次解析；每首每轮最多三次，成功即播放，全部明确失败后跳过。等待按状态推进，用户可主动取消。平替可能是翻唱、混音或其他歌手版本，不承诺原录音准确匹配。
- 修复少量候选失败后不能重新搜索，以及移动端异步开关回调恢复旧队列的问题；原曲资料、歌单顺序和其他用户资料保留。
- 漫游可通过上一首重听最近三首实际播放的歌曲，之后继续漫游。
- 补齐 PC 歌单管理等页面的顶部拖动区；修复长错误提示溢出及关闭按钮无法点击。

两端实际安装包身份与资源摘要核验通过，Android 与 r46 使用同一正式证书；更新与 Windows 安装器定向检查 23 项通过。实际读取两份 QQ 歌单共 312 首，抽样完成真实 PC 音源的静音解码、连续播放、取消及关联复用验证；312 仅为导入数量，不是逐首播放通过数。未新增安卓真机或系统覆盖升级验收。

## r46 初始发行记录

本版合并 PC 与 Android 的导入歌单播放、平台平替、状态驱动加载和 Windows 升级兼容修复。

- 修复 QQ 等平台导入歌曲的音源选择与跨目录同录音匹配。
- 歌单管理新增平台平替：自动开关、扫描、选中处理、版本确认、跳过、取消和恢复原曲。原曲信息、顺序、喜欢与收藏保留。
- 每首每轮最多尝试三个候选；第三次成功仍可正常播放。已接受候选的播放接续不重复占用新候选，明确失败才使用剩余额度，不进入第四个候选。
- 解析、音频接收和缓冲按实际状态等待，不因累计加载时长强行中断。支持用户主动取消；保留 TLS、网络权限和发行校验。
- 修复取消期间的迟到解析与关联写入，恢复原曲/改选后的缓存身份，以及 Android 队列撤销丢失歌单上下文的问题。
- Windows 安装与卸载使用原生进程检查；补齐旧卸载器 PowerShell 前置流程的兼容处理，保留覆盖升级资料与标准安装流程。

Android 沿用 `com.zenix.musicplayer` 和原正式发行证书；Windows 沿用既有应用身份及签名清单信任方式。本版公开版本 1.0.3，双端内部构建 46。旧正式客户端继续使用原内置 stable/preview 签名清单入口，重新检查更新可获取本版；已有历史工件与下载地址保留。

本轮已完成两轮聚焦 Review、针对性回归及构建校验。按用户约定跳过完成后的额外用户层面测试；未重新验证所有设备的实际播放、全歌单在线资源或真实系统覆盖升级，不把编译、自动测试及上传成功表述为实机通过。第三方音乐源的实际可用性取决于其上游服务。
