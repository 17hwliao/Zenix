# Zenix Android 0.2.0 · 预览版 1

首个公开 Android 预览版。复用 Zenix 的 React 视觉，使用 Capacitor 与 Java/Media3 原生音频服务，不运行 Electron。

## 本版内容

- 自定义音乐源导入、搜索、按接入顺序解析与品质降级、失败后继续尝试后续源。
- 原生播放、媒体通知、本地流式缓存、喜欢、收藏、去重历史、自定义歌单及本地歌曲备用入口。
- 手机个人空间、名片编辑、图片或视频背景。环绕卡片使用连续角度、跟手拖动、有限惯性和弹簧吸附，按钮与触控使用相同逻辑。
- 原生层统一窗口背景，处理输入法与安全边距后向 WebView 传递已归零的边距，避免重复留白。
- 音乐空间共用桌面版有限贴纸拼版算法，每首歌只出现一次。触摸拖动画布、点击聚焦、其余贴纸平滑排布；点击底部歌曲条聚焦当前播放歌曲。
- 聚焦贴纸与应用内歌词支持浏览、点击跳转、3 秒回到当前歌词。
- 原生跨应用三行悬浮歌词：简约半透明贴纸、顶部拖动、歌曲进度跳转、播放控制、喜欢、收藏、返回主窗口、字号/字体/颜色、标准/紧凑布局。
- 锁定悬浮歌词后，歌词窗口不接收触摸，仅保留独立小解锁按钮。关闭屏幕后暂停歌词界面更新。

## 安装

下载 `Zenix-Android-0.2.0-preview.1-debug.apk`，系统要求 Android 7 / API 24 或更新版本，并使用较新的 Android System WebView。

首次使用自行导入音乐源，或选择本地音乐。APK 不包含音乐源脚本、歌曲、个人背景、用户配置和缓存，无需登录。

悬浮歌词可在播放器或设置中开启；首次开启需由用户在 Android 系统页允许“显示在其他应用上层”。系统安全窗口和主动禁止悬浮层的应用可能不显示歌词；悬浮歌词不尝试覆盖或绕过这些窗口。

## 验证与版本性质

这是开发签名的 **Debug 预览包**，不是正式商店发行版本。已完成 TypeScript/桌面与 Android 构建、手机宽度下的浏览器转卡交互观察；当前开发机器没有连接 Android 设备，输入法、后台/锁屏播放、悬浮权限、透传与手机厂商省电策略仍待真机验收。暂不替换 Windows 0.1.0 稳定下载入口。

缓存仅对已完整缓存的渐进式音频支持直接复用；不保证未完整下载或 HLS 分片的完整离线播放。Android 悬浮歌词目前解析 LRC 与逐字时间戳文本；没有有效时间戳时展示歌曲信息及未找到歌词状态。

校验文件为 `Zenix-Android-0.2.0-preview.1-debug.apk.sha256`。正式 Android 发行签名与资料备份/跨设备同步后续另行配置。
