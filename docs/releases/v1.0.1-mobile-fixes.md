# v1.0.1 移动端修补（待真机验收）

此修补以已发行 v1.0.0 为基线，Android / iOS build 增至 6，不覆盖首版安装包或标签。

## 按截图顺序修补

1. **输入法遮挡**：Android 仅补足尚未由系统消耗的 IME 高度；原生键盘事件与 visualViewport 共同确定可见高度。输入时隐藏底部导航与迷你播放条、缩减页面底部留白，必要时滚动使输入框可见。iOS 同步键盘事件，并保留 WKWebView 的原生键盘处理，避免再次扣除高度。
2. **金卡与环绕卡片**：按住金卡向上拖动超过 64 CSS 像素，切换到环绕卡后方；再次上抛可取回，前后位置保存在本机。普通点击仍打开编辑，左右拖动仍转卡；环绕区只展示前半圈，通常三张卡，其余保留在旋转序列中。箭头按钮提供等价入口。
3. **HTTP 地址入口**：切换页面回到顶部，音乐源页明确展示链接表单，支持公开 HTTP / HTTPS 脚本和完整源地址。保留原有网络及脚本权限检查。
4. **源包读取失败**：Android / iOS 改用原生文件选择和受限字节读取，支持 `.zenixsources`、相同格式的 `.json`、包含清单的分享 ZIP，保留完整性校验、预览与确认。单脚本入口独立保留。

## 验收边界

构建、浏览器手机尺寸下的卡片手势与页面检查分别记录；浏览器不具备手机输入法、原生文件提供器或后台播放能力。仍需在原问题 Android 设备及 iPhone 上检查：

- 源地址、分享链接、资料编辑、搜索四处输入，输入框持续可见，关闭键盘后导航正常返回。
- 向上抛出与取回金卡，动画结束不自动还原，重进主页保留层级。
- 从文件管理器、QQ 保存目录、iOS 文件应用选择分享包；完整包无需重新下载脚本即可预览并按顺序安装。
- 上游初始化或播放服务失败应显示逐项原因，不把导入成功当作在线播放成功。

软件安装包不附带第三方音乐源或个人配置；分享资料由用户单独转发。
