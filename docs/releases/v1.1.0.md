# Zenix v1.1.0 · r55

本次为新功能迭代，公开版本升级到 **1.1.0**，Android/Windows 内部构建均为 **55**。

新增“音乐工作台”，整合空间书签与分区、私人片段与歌词检索、歌单撤销、离线收纳及网络偏好、版本试听与练习、漫游控制与临时探索、后台任务、设备接力/投稿/选择同步，以及可换皮肤的音乐助手和桌宠。

缓存复用、原录音身份、取消和资料恢复经过统一修正。自动平替仍每轮最多三个候选，按实际状态等待；贴纸浏览、聚焦、放大与播放保持独立。

## 更新与资料

沿用原 Android 发行证书、包名、更新签名和用户资料目录；内部构建号递增。保留旧安装包及地址，不要求卸载或清空资料。新工件使用新文件名，上传核验后才切换正式/预览清单。

- Android：`Zenix-Android-1.1.0-r55.apk`
- Windows x64：`Zenix-Setup-1.1.0-r55-x64.exe`
- 校验：`SHA256SUMS-1.1.0-r55.txt`

Windows 沿用签名清单信任模式，并无新增 Authenticode 发行证书。

## 验证与使用边界

269 项本地回归全部通过；双端 Web、Android Release、Windows NSIS 构建和实际包身份核验通过；真实旧 Windows r28 校验代码接受新签名清单。详细范围、修复项和限制见[本轮审查](../review-feature-iteration-2026-10-23.md)。

本轮按用户约定跳过新增实机/手动体验验收，不宣称本工件已完成双端实际安装升级验收。设备协作需要原局域网配对与接收方授权；系统语音、Android 悬浮依赖设备能力及权限。语音唤醒留在后续阶段。

新功能为可选入口，不内置私人音乐源，不要求账号或助手 API Key。
