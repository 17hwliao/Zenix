# Zenix v1.2.0 · r56

星音固定音乐指令更新，包含上一轮本地角色、语音、歌词与换装成果。Windows x64 与 Android 同一公开版本和内部构建。

- 暂停、下一首、单曲循环、音量调整、点名搜索与当前/相邻十首以内歌曲信息查询。
- 纯净歌词、当前录音歌词校正、五句透明悬浮歌词与窗口拖动；悬浮歌词文字不跳播。
- 缓存歌单、后续仅缓存网络偏好、任务查看、空间与分区导航、位置书签、漫游歌曲减量与三首轻音乐临时探索。
- 本周统计、睡眠定时、已配对手机向电脑接力/投稿、歌单导出和原通道检查更新。
- 原创 Zenix 星音、拖动修复、害羞/招手/聆听动作、八套服装预览保存；这是 Live2D 风格图像与姿态，不是真正 Cubism 模型。
- PC 前台空白区域按住空格说话，Android 应用内按住语音按钮；文本与语音共用固定指令，低置信度与资料/网络偏好写入需确认。不接通用大模型，不常驻监听唤醒。

本轮全量相关改动 Review 和修复后，完整本地回归 294/294 通过。角色外观、语音与业务数据分开，保留用户现有歌单、喜欢、收藏、配置和原发行身份。版本高于 1.1.0/r55，历史安装包与原更新入口继续保留。发布按先核对工件大小/摘要、后切换签名清单执行。

限制：语音识别取决于系统服务；临时探索需已经开始漫游且结果由音乐源提供；跨设备需局域网配对与授权；仅缓存设置约束后续请求，已建立的播放连接可能继续传输；没有实际监听系统所有网络进程。用户层面测试按既有约定跳过，未将自动检查写为完整实机覆盖升级验收。
