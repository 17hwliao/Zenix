# Zenix v1.0.1 / r39 移动播放修复

本修订包含 r38 的审查与动画改进，并修复移动端慢源加载过早失败及错误提示无法关闭的问题。Android 与 Windows 的应用版本为 1.0.1，内部构建号为 39。

## 修复内容

- 原 Android 解析总预算 30 秒、每源最多 10 秒且继续按源数量分摊；七源队列时单源约 4.3 秒，初始化、搜索、品质解析共同消耗这段时间。调整为每源最多 45 秒、总预算最多 180 秒，不再因增加源而缩短单源等待。
- 源 API 默认读取等待及整个请求上限为 30 秒，保留脚本指定的更短等待；连接最多 15 秒。音频流读取允许 45 秒无数据等待，连续有数据的播放不设置整首下载期限。
- 取得地址后单独等待音频缓冲；缓冲耗时不再扣除后续资源解析的剩余时间。完整缓存优先本地读取，部分缓存仍需要网络，不伪称整首离线。
- 主动停止加载会取消解析或缓冲，保留已写入缓存与恢复位置；不因浏览页面而取消播放。
- 播放失败旁的叉号改为 44px 可点击关闭按钮；关闭不重试、不切歌，同一失败快照重复到达不会让提示重新出现，新的失败仍能显示。
- 普通操作提示增加关闭按钮，面板关闭按钮扩大触摸区域。保留原贴纸拼贴、聚焦和独立播放 / 放大行为。

## 更新与验证

新地址使用独立 `v1.0.1-r39` 标签与带 r39 的文件名，原下载地址继续保留。固定 stable / preview 入口、RSA 公钥、schemaVersion 1、APK 包名与原正式证书均保持一致。两端递增 build 39，签名清单包含安装包大小及 SHA256。

38 项更新 / TLS / 重定向 / 取消 / 发行 / 安全定向回归通过，另有生产 Android 源队列与缓存判断 JVM 回归、真实 React 移动界面关闭及取消用例通过。慢源夹具使用“你不知道的事”和“像风一样”的歌曲元数据，模拟初始化及资源等待累计 30 秒，验证七源队列不会提前取消；它没有连接第三方真实音乐服务，不能证明任一音乐源当前在线或这两首歌的实际播放已实测。

桌面与移动 Web、原签名 Android Release、Windows NSIS 构建和实际工件身份 / 原更新入口核验通过；与既有 r35 APK 实际核对原证书。Windows 继续使用签名清单及摘要信任，没有 Authenticode 发行证书。

本次未操作手机或执行用户手动体验 / 系统覆盖安装；这些用户层面测试按当前明确指令跳过。编译、自动回归、签名清单及远程工件核验不代表已完成每台设备的真实升级或播放验收。Android 安装依然需要系统许可和用户确认；网络或第三方源不可达仍可能导致下载 / 播放失败。

上次 r38 远程 CI 失败分别发生于测试证书生成的 15 秒进程期限和 Electron 界面夹具的 45 秒外层期限。本修订给夹具生成及整段冷启动留出时间并增加 UI 进度日志，保留 TLS、证书拒绝、界面行为断言及单次界面条件等待上限，未放宽产品安全校验或性能断言。
