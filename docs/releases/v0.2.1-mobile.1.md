# Zenix 0.2.1 移动预览版

## 下载与运行

- Zenix-Android-0.2.1-preview.1-debug.apk：Android 7.0 及以上，开发签名 Debug APK，可安装或覆盖同签名上一预览版。
- Zenix-iOS-0.2.1-Simulator.zip：Mac / Xcode Simulator 使用的未签名 App，不是 iPhone IPA。解压后使用 xcrun simctl install booted 安装。
- Source code：完整 Android、iOS 与桌面工程；iOS 先执行 npm ci 和 npm run ios:sync，再打开 Xcode 工程。
- SHA256SUMS-0.2.1.txt：校验下载文件。

## 本轮改动

- 新增 Swift / AVPlayer / JavaScriptCore iOS 原生适配，后台音频、系统媒体控制、私有配置、流式磁盘缓存、自定义源与应用内歌词。
- 修复首次云端编译发现的 Swift 回调捕获问题，Xcode 26.6 原生编译通过。
- 共用手机端连续环绕卡、玻璃搜索条、有限歌曲贴纸和安全区布局。
- Android 压缩音频缓冲目标 4 MiB，iOS 前向缓冲偏好 15 秒；不是 App 总内存上限。
- 不可见贴纸封面卸载，预读边缘保留；封面记忆化和异步解码，背景视频与页面状态更新在后台暂停。
- 原生配置按字段读取，减少缓存和浮层操作复制完整歌曲库产生的分配。

## 构建与边界

Android Gradle 构建、APK v2 签名校验与版本信息检查完成，包内未发现音乐源脚本、个人配置、歌曲或视频。iOS [云端构建](https://github.com/17hwliao/Zenix/actions/runs/36964915152)完成。

没有连接真机，本轮不提供设备实测 MB 降幅，也未完成系统能力和实际音乐源的设备验收。iOS 未签名，不提供跨应用悬浮歌词；Android 浮层需用户授权。音乐源由用户自行配置，公开源码与安装包不含预置源、账号或个人音乐资料。

更多见 [Android](../android.md)、[iOS](../ios.md)、[内存策略](../mobile-performance.md)。
