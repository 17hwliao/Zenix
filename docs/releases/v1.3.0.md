# Zenix v1.3.0 · r57

> 最新维护修订为 [r59](v1.3.0-r59.md)。下文保留 r57 的首次发行记录。

音乐空间增加展示风格选择，Windows x64 与 Android 使用相同版本。

- 保留默认贴纸拼贴，新增多轨环绕和简约列表，搜索结果也可切换。
- 环绕中心拖动／滚轮转动全部轨道，单个分支独立浏览；支持卡片大小、键盘与触摸操作。
- 点卡片只聚焦，明确点击播放才播放；放大仍使用原歌曲详情与纯净歌词。
- 简约列表显示歌名、歌手、专辑、时长和状态，保留收藏与来源选择，所有歌曲可继续加载浏览。
- 展示偏好独立保存，切换不重置歌单、音源、播放队列或旧贴纸镜头；新风格改变焦点后返回贴纸可见。
- 修复新风格下旧书签恢复／分区加入、取消拖动后点击无响应和拖动中卡片卸载中断的问题。

此前用户 issue #5 的角色动作／换装、#6 的五句悬浮歌词／纯净歌词已在 v1.2.0/r56 发行。本版保留这些成果，并关联关闭对应已交付请求。

沿用原 Android 包名、发行证书、更新公钥和用户资料目录，双端构建递增至 57。历史工件和旧下载地址保留，新安装包核对后才切换正式／预览签名清单。用户无需卸载或清空资料。

全项目主要调用与状态边界、变更代码及截图已经审查，确认的问题已最小修复。最终完整本地自动回归 **302/302 通过**，双端安装包构建及身份核对通过。结果见 [Review 记录](../review-space-presentation-2026-10-26.md)。PC 1440 和手机 390／320 宽的隔离实际渲染已检查，卡片互不遮挡、中心播放入口可见；短屏内容在空间内部滚动。

限制：环绕角度暂不保存为位置书签，保存镜头仍需切回贴纸，已有书签可恢复。碰撞与背面卡片暂时隐藏，轨道前后入口能访问全部歌曲。未宣称真实手机帧率；用户已确认完成，后续用户层面测试按约定跳过，未执行在用客户端安装或新工件的真机完整升级验收。
