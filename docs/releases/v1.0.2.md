# Zenix v1.0.2 / r41

本轮将已批准的功能迭代、移动端补齐和 Review 修复合并为一次 Windows / Android 更新。公开版本 1.0.2，内部构建 41；沿用原包名、Android 正式证书、清单签名公钥和更新入口。

## 新增与完善

- 搜索建议与最近搜索记录，支持清空；建议来自本机可见曲库，不上传搜索历史。
- 播放队列支持下一首播放、加入队列、重排、批量移出和撤销；PC 大队列整理保留当前音频连接和进度。
- 歌单批量复制、移动、排序、移出和重复候选核对；不自动删除相似录音。
- QQ 音乐、网易云音乐、酷我公开歌单链接迁移：分页读取、预览、确认后创建独立歌单；不完整结果需要额外确认。仅迁移曲目信息，播放使用用户自己的音乐源。
- 按歌曲保存歌词时间校正，调整字号、行距、字重、翻译及当前句突出；原生悬浮歌词接入时间校正。
- 设置分类与本地设置搜索，支持跳转定位；调整面板尺寸、按钮留白及圆角选择菜单，Android 提供适合窄屏的入口。
- 手机局域网遥控 PC：电脑开启服务，手机输入地址和配对码，电脑确认后控制播放、切歌、进度和音量。Android 可直接在应用内操作；不投送音频或替换手机队列。
- PC 输出设备选择、测试音、自定义应用内/全局快捷键、均衡器与声音预设；Android 均衡器接入实际音频会话，输出路由由系统管理。
- PC 关闭窗口驻留托盘，托盘菜单可完全退出；音乐小窗增加置顶、紧凑布局和位置记忆。
- Android 加载通知展示歌曲与控制入口；完善脚本 Buffer 兼容及受限 VPN Fake-IP DNS 处理，新兼容源导入时一并确认 HTTP 公网权限。
- 歌手与专辑浏览聚合已收录曲库、收藏和播放记录；不宣称为完整在线作品目录。

保留贴纸音乐空间、聚焦展开与周围让位、明确播放/全屏按钮及独立队列管理入口。Review 修复了 Android 选歌提前向 ExoPlayer 提交无 URI 媒体项、PC 空队列下一首不播放及大队列无法整理的问题。

## 更新与验证边界

旧版固定的正式/预览入口、公钥和清单格式继续兼容；新构建号高于已发 r39 和本地 r40。同名旧工件不覆盖，历史包和链接保留。先核对新上传文件的大小和 SHA256，再切换更新指针。Android 安装确认仍由系统和用户完成，正常更新保留应用资料。

已完成两轮聚焦 Review 及相应源码自动检查；生产选歌方法的 JVM 用例仍使用平台/解码边界夹具，界面回归也不等于手机性能或系统安装验证。用户已确认此前阶段完成，后续用户层面测试按约定跳过；本轮不操作原客户端或手机，不声称所有设备、音乐源或覆盖安装已重新验收。发行工件另核对原签名、包身份、版本、内置更新配置及清单与文件一致性。
