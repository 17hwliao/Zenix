# Zenix v1.0.0

当前维护基准：Android **r33**，Windows **r28**。Android 保留本轮优化后的原签名安装包；Windows 保留当前稳定安装包。本次没有生成新的构建或验收版本。

移动端优化页面切换、音乐空间进入与贴纸聚焦、歌曲详情页展开和收起，保留原贴纸拼贴布局、点击展开及周围让位。当前完整源码收拢到 main。
