# Zenix v1.0.0

公开版本保持 **v1.0.0**，当前修订 **r7**，Android / iOS 内部构建号 **7**。按作者确认的流程，每次完成修补后替换本稳定版的三端下载工件，并同步标签与源码；只有作者和测试人员共同确认可发布时，才递增公开版本号。移动端内部构建号始终递增，保持同签名覆盖升级的顺序。

## 发行内容

- Windows x64：`Zenix-Setup-1.0.0-r7-x64.exe`，NSIS 安装包；支持原生全屏与还原，包含桌面三行歌词、个人卡片、歌曲贴纸和自定义音乐源管理。
- Android：`Zenix-Android-1.0.0-r7.apk`，正式发行密钥签名；React / Capacitor 界面、Media3 原生播放、缓存、歌单、歌词及源包导入。
- iOS：`Zenix-iOS-1.0.0-r7-Simulator.zip`，Release 配置的未签名模拟器 App；完整 Swift / AVPlayer 工程随源码提供。
- `SHA256SUMS-1.0.0-r7.txt`：发行包 SHA256 校验值。
- `stable.json`：由发布清单私钥签署的 Android 更新信息，不包含私钥。

## 本次修补

- Android / iOS：页面短淡入与轻位移；底部导航选中层平滑移动，搜索、编辑面板和完整播放器补齐打开与关闭过渡。尊重系统“减少动态效果”。页面退出后释放原页面，后台原生播放不重启。
- 输入法高度避免重复扣除，输入时隐藏底部控件，输入区域跟随可见视口。
- 金卡可上抛到环绕卡后方并取回；环绕区通常只展示三张卡。
- 音乐源恢复明确的 HTTP / HTTPS 导入入口；分享 ZIP / JSON / .zenixsources 使用原生文件读取，保留校验、预览和确认。
- PC：首页滚轮只滚动页面，不再触发环绕卡旋转；点击拖拉转卡保持原逻辑。

## 更新与迁移

Android 正式用户后续使用同一发行密钥、递增 versionCode，可通过设置中的应用更新覆盖安装。旧 Debug APK 的签名不同，不能直接覆盖；旧应用中的私有资料不会被自动迁移。不要先卸载旧应用再寻找资料，当前没有统一移动端配置导出功能。

Windows 安装器保留应用用户资料。当前没有受信任代码签名证书，安装包为未签名状态，系统可能提示未知发布者；自动安装功能要求验证有效 Authenticode 签名，首版不将未签名 EXE 放入正式自动更新清单。请从本仓库 Release 手动下载安装。

iOS 包只能在 Mac 的 iOS Simulator 中运行，**不能安装到 iPhone，也不是 IPA**。iPhone 发行、TestFlight 和 App Store 更新需后续提供 Apple 证书、描述文件、开发者团队及渠道地址。iOS 没有 Android 式跨应用悬浮歌词。

音乐源需用户自己配置，可在三端导入分享源包或 HTTPS 链接。发行包不附带音乐源脚本、个人配置、歌曲或缓存。源脚本的服务可用性独立于客户端版本。

修补保持 package.json、Android versionName、iOS MARKETING_VERSION 为 1.0.0，递增 versionCode / CURRENT_PROJECT_VERSION；工件带 rN 修订标识。发布工具先上传核对新三端工件，再替换原稳定版资产。更新清单在 APK 已可下载后提交 main，沿用原发行身份。当前标签随稳定修订更新，Git 提交历史保留。Windows 同公开版本修补需要从 Release 手动安装；Android 按 build 检查更新。
