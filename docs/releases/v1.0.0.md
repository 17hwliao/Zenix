# Zenix v1.0.0

公开版本保持 **v1.0.0**，当前 Android 修订 **r11**，内部构建号 **11**；Windows 保留 r7。按作者确认的流程，每次完成修补后替换本稳定版的 Windows / Android 下载工件，并同步标签与源码；只有作者和测试人员共同确认可发布时，才递增公开版本号。移动端内部构建号始终递增，保持同签名覆盖升级的顺序。

## 发行内容

- Windows x64：`Zenix-Setup-1.0.0-r7-x64.exe`，NSIS 安装包；支持原生全屏与还原，包含桌面三行歌词、个人卡片、歌曲贴纸和自定义音乐源管理。
- Android：`Zenix-Android-1.0.0-r11.apk`，正式发行密钥签名；React / Capacitor 界面、Media3 原生播放、缓存、歌单、歌词及源包导入。
- `SHA256SUMS-1.0.0-r11.txt`：发行包 SHA256 校验值。
- `stable.json`：由发布清单私钥签署的 Android 更新信息，不包含私钥。

## 本次修补

- Android / iOS：轻点歌曲贴纸只聚焦放大，不改变当前播放；点击贴纸的播放按钮才切换歌曲。当前歌曲的暂停/继续及展开功能保持原行为。
- Android / iOS：页面短淡入与轻位移；底部导航选中层平滑移动，搜索、编辑面板和完整播放器补齐打开与关闭过渡。尊重系统“减少动态效果”。页面退出后释放原页面，后台原生播放不重启。
- 输入法高度避免重复扣除，输入时隐藏底部控件，输入区域跟随可见视口。
- 金卡可上抛到环绕卡后方并取回；环绕区通常只展示三张卡。
- 音乐源恢复明确的 HTTP / HTTPS 导入入口；分享 ZIP / JSON / .zenixsources 使用原生文件读取，保留校验、预览和确认。
- PC：首页滚轮只滚动页面，不再触发环绕卡旋转；点击拖拉转卡保持原逻辑。

## 更新与迁移

Android 正式用户后续使用同一发行密钥、递增 versionCode，可通过设置中的应用更新覆盖安装。旧 Debug APK 的签名不同，不能直接覆盖；旧应用中的私有资料不会被自动迁移。不要先卸载旧应用再寻找资料，当前没有统一移动端配置导出功能。

Windows 安装器保留应用用户资料。当前没有受信任代码签名证书，安装包为未签名状态，系统可能提示未知发布者；自动安装功能要求验证有效 Authenticode 签名，首版不将未签名 EXE 放入正式自动更新清单。请从本仓库 Release 手动下载安装。

iOS 真机 IPA 是未签名的封装，**须自行签名后侧载，不能直接点击下载文件安装**；模拟器 ZIP 仍仅供 Mac 的 iOS Simulator 使用。当前没有 Apple 发行身份，也没有 TestFlight / App Store 发行；后续正式分发需配置相应凭据与渠道。签名说明见 [iOS 工程文档](../ios.md)。iOS 没有 Android 式跨应用悬浮歌词。

音乐源需用户自己配置，可在三端导入分享源包或 HTTPS 链接。发行包不附带音乐源脚本、个人配置、歌曲或缓存。源脚本的服务可用性独立于客户端版本。
