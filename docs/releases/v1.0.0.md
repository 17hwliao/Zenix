# Zenix v1.0.0

Windows、Android、iOS 源码统一为首版基线；后续修补递增到 v1.0.1、v1.0.2，不移动已发行标签，不覆盖同名安装包。内部移动端构建号为 5，不重置系统用于覆盖升级的计数。

## 发行内容

- Windows x64：`Zenix-Setup-1.0.0-x64.exe`，NSIS 安装包；支持原生全屏与还原，包含桌面三行歌词、个人卡片、歌曲贴纸和自定义音乐源管理。
- Android：`Zenix-Android-1.0.0.apk`，正式发行密钥签名；React / Capacitor 界面、Media3 原生播放、缓存、歌单、歌词及源包导入。
- iOS：`Zenix-iOS-1.0.0-Simulator.zip`，Release 配置的未签名模拟器 App；完整 Swift / AVPlayer 工程随源码提供。
- `SHA256SUMS-1.0.0.txt`：发行包 SHA256 校验值。
- `stable.json`：由发布清单私钥签署的 Android 更新信息，不包含私钥。

## 更新与迁移

Android 正式用户后续使用同一发行密钥、递增 versionCode，可通过设置中的应用更新覆盖安装。旧 Debug APK 的签名不同，不能直接覆盖；旧应用中的私有资料不会被自动迁移。不要先卸载旧应用再寻找资料，当前没有统一移动端配置导出功能。

Windows 安装器保留应用用户资料。当前没有受信任代码签名证书，安装包为未签名状态，系统可能提示未知发布者；自动安装功能要求验证有效 Authenticode 签名，首版不将未签名 EXE 放入正式自动更新清单。请从本仓库 Release 手动下载安装。

iOS 包只能在 Mac 的 iOS Simulator 中运行，**不能安装到 iPhone，也不是 IPA**。iPhone 发行、TestFlight 和 App Store 更新需后续提供 Apple 证书、描述文件、开发者团队及渠道地址。iOS 没有 Android 式跨应用悬浮歌词。

音乐源需用户自己配置，可在三端导入分享源包或 HTTPS 链接。发行包不附带音乐源脚本、个人配置、歌曲或缓存。源脚本的服务可用性独立于客户端版本。

## 验证范围

本次重新执行 TypeScript / Vite 构建、Windows NSIS 打包、Android Release 编译及 APK 签名核对、GitHub macOS 原生 iOS 模拟器构建。构建结果以实际发行工件和 Actions 记录为准。此前回归与内存数据见 `docs/regression-memory-2026-10-03.md`，不代表本次三端完整真机验收；未声称获得所有场景最低内存。

## 后续发布

对 v1.0.0 的修补从对应标签创建分支，正常提交后建立新的 v1.0.x 标签。发布时同步 package.json、Android versionName / versionCode、iOS MARKETING_VERSION / CURRENT_PROJECT_VERSION，并在安装包上传成功后签署及提交更新清单。
