# Zenix v1.0.0 · 稳定修补 r18

公共版本继续 **v1.0.0**；Windows 内部 build / Android versionCode 递增到 **18**。本轮整合 build 16 / 17 新功能并修补移动交互。

## 修补与功能

- Android 页面连续淡入淡出，导航不影响原生播放；减少动态效果时停用过渡。
- 搜索表单按钮分区，搜索结果改为封面 / 歌名 / 歌手与独立播放键的滚动列表，长标题省略、窄屏和键盘视口布局修复。
- 应用内删除、清缓存、安装更新确认与更新提醒采用圆角玻璃样式。取消或返回不执行操作；Android 系统授权和安装界面由系统绘制。
- 音乐空间单击 / 双击贴纸只聚焦，长按快捷操作，不切歌、不自动放大；明确的播放 / 放大按钮分别执行对应动作。
- 歌单 `.zenixlist` 导出导入、Windows / Android 局域网主动迁移、实际听歌统计与回忆卡、停止播放的睡眠定时器，以及 Android 桌面组件 / Windows 音乐小窗。
- 移动端播放解析与浏览取消范围隔离，后台加载保护、左右滑动移出、长按喜欢 / 收藏动画、完整 / 部分缓存提示和复用、手动音源顺序与最近成功源优先。

Android 正式用户后续使用同一发行密钥、递增 versionCode，可通过设置中的应用更新覆盖安装。旧 Debug APK 的签名不同，不能直接覆盖；旧应用中的私有资料不会被自动迁移。不要先卸载旧应用再寻找资料，当前没有统一移动端配置导出功能。

iOS 已暂停发行，当前稳定版不提供 IPA 或模拟器安装包。工程和历史构建记录保留，签名说明见 [iOS 工程文档](../ios.md)。

音乐源需用户自己配置，可在三端导入分享源包或 HTTPS 链接。发行包不附带音乐源脚本、个人配置、歌曲或缓存。源脚本的服务可用性独立于客户端版本。
