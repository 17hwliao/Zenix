# Zenix v1.0.4 · r50

本次同时更新 Android 和 Windows，公开版本由 1.0.3 升至 1.0.4，内部构建递增至 50。

- 新增文本歌单导入：在“歌单分享与迁移”中粘贴歌曲清单，或选择 UTF-8 `.txt`、`.csv`、`.tsv` 文件。
- 支持编号清单、“歌名 - 歌手”、歌手《歌名》、纯歌名、带表头的多列文本；可选择歌名或歌手在前，并先预览识别结果。
- 文本清单保存为独立歌单，默认启用播放时自动搜索匹配，沿用最多三个候选、按状态等待与取消机制。可以关闭自动匹配；原歌单、喜欢、收藏及设置继续保留。
- Android 支持将其他应用的文本分享到 Zenix，先查看、解析，再确认导入，不自动写入资料。
- Android 音乐空间支持双指捏合缩放，保留单指拖动、贴纸聚焦及播放按钮；缩放不切歌、不自动打开全屏播放器。

现有 QQ、网易云、酷我公开歌单链接导入继续保留。按本轮最终需求，不增加汽水或 LX 专用解析。文本导入不包含音频和音乐平台权限；播放使用用户自己配置的音乐源，纯歌名可能匹配到不同歌手或版本。一次最多 5000 首，文件最大 2 MiB。

本地全套回归 164/164 通过，审查修正后的受影响路径专项 20/20 通过，两端构建及包内身份、资源核验通过。

本轮仅进行本地自动验证，未执行手机或电脑的实际覆盖安装和人工体验验收，不能视为本次实机升级已通过。原 Android 包名与证书、更新签名公钥、安装包摘要校验和递增构建保持；历史下载工件不删除、不替换。检查更新可获取本版的状态以正式签名清单发布后核对结果为准。
