# 歌单分享、音乐回忆与桌面组件

这组功能首次集成到 Windows / Android 的本地开发构建 16，后续 build 17 保留，公共版本仍为 1.0.0。当前公开稳定版为 r15，更新清单未切换；本文不表示已经发行。iOS 继续暂停发行。最新移动端优化见 [播放与手势](mobile-playback-and-gestures.md)。

## 功能入口

在播放器设置中进入“歌单分享与迁移”“听歌统计与回忆”“睡眠定时器”或“桌面音乐组件”。歌单管理也提供分享入口，可以直接带入当前歌单。四个板块使用同一个音乐工具面板，沿用 Zenix 的玻璃、渐变和宇宙卡片风格。

## 歌单文件

1. 选择一个或多个自定义歌单，点击“导出歌单文件”，保存为 `.zenixlist`。
2. 将文件交给同样使用 Zenix 的人。
3. 接收方点击“导入歌单文件”，查看歌单名称、歌曲数量和本地歌曲数量，再确认导入。

导入会创建独立歌单，同名自动加“（导入 N）”后缀；不会覆盖现有歌单，也不会替换喜欢、收藏、历史或音源配置。文件保留歌曲顺序以及在线歌曲的平台和歌曲标识，接收方通过自己的音乐源解析播放。没有配置可用源时，仍可先保存清单。

文件只包含歌单和必要的歌曲信息，不包含音频、封面、本机文件路径、播放地址、源脚本、账号或授权设置。本地歌曲按标题、歌手、专辑和时长与接收方已有曲库匹配；无法匹配的歌曲保留在歌单中并提示不可用。补充本地文件后重新导入，可以重新匹配。

格式为 UTF-8 JSON，顶层标识 `format: "zenix-playlist"`、`schemaVersion: 1`、`playlists` 数组。单次最多 100 个歌单、合计 5000 首歌曲，文件大小最多 2 MiB。两端均校验版本、字段和大小。

## 同局域网主动迁移

1. 两端连接同一局域网，可以是同一 Wi-Fi，也可以是同一路由器下的 Wi-Fi 与有线网络。
2. 在接收端点击“开启接收 / 查看本机 IP”。面板直接显示可填写的 `IP:端口` 和配对码，分别支持复制。
3. 在发送端选择歌单，填入接收端地址和配对码，点击“发送所选歌单”。
4. 接收端查看预览并确认导入，发送完成提示只代表已送达。

Windows 与 Android 共用文件协议及 AES-256-GCM 传输协议，可以双向发送。无需账号或外部 IP 查询网站，地址来自设备当前局域网接口。有多个地址时选与发送端同网段的地址。只需填写接收端地址；反向迁移时交换发送、接收角色。

接收由用户主动开启，最长持续 15 分钟，可随时结束；成功接收一批歌单后自动关闭监听。一次只能保留一个待确认批次。仅接受私有 IPv4 地址，配对码用于派生加密密钥，请将地址和配对码一起交给目标设备用户。接收端需保持 Zenix 打开；Android 初步方案建议在前台接收。无法连接时检查 IP 和端口、接收状态、Windows 防火墙及路由器客户端隔离。

## 听歌统计与回忆卡

统计记录实际播放的墙钟时间，暂停、缓冲和解析等待不累计，拖动进度不把跳过的歌曲时长计入。每次选曲或重复播放听满 30 秒，或短曲的一半，记为一次有效播放。

可查看最近 7 天、本月和今年的聆听时长、有效播放、歌曲数量、有音乐的日子、歌曲和歌手排名，以及聆听日历。记录保留最近 366 天。过去的近期历史本身已去重，不会补算成聆听统计；新数据从使用本功能后开始积累。

回忆卡提供“极光玻璃”“暖金名片”“深夜宇宙”三种样式，可以保存为 1080×1350 PNG。导出的卡片展示当前所选周期的统计及陪伴最多的歌曲。Android 在原生播放服务中记录，Windows 在主播放器中记录；两端统计各自留在本机，歌单迁移不会传输统计。

## 睡眠定时器

默认预设为 15、30、60、90 分钟，支持自定义 1–720 分钟，也可以指定未来 12 小时内的停止时间。面板显示倒计时和预计停止时间，可以取消，重新设置会替换原任务。

到期只停止播放，保留应用、歌单及播放状态，不退出应用或关闭设备。执行逻辑在 Electron 主进程 / Android 原生播放服务中，关闭工具面板后继续执行；同时取消待完成的解析和漫游续播，避免定时停止后又开始播放。Windows 退出应用会取消任务；Android 保存停止时间，服务恢复时检查是否到期，不自动启动歌曲。断电、强制停止或系统结束服务后的执行不视为已经保证。

## 桌面音乐组件

Android 提供 3×3、4×2、4×1 三种系统桌面组件，显示当前歌曲并提供上一首、播放/暂停、下一首和打开应用。可以在面板点击“添加到桌面”，或长按桌面，在小组件列表中选择 Zenix。组件支持拉伸，实际网格和尺寸由桌面启动器决定。

Windows 提供相同比例的独立音乐小窗，初始尺寸分别为 300×300、400×200、430×130。可以拖动、缩放、切歌、播放/暂停和召回主界面。此处的尺寸选项表示布局比例；小窗不是 Windows 系统小组件面板项目，使用时需要保持 Zenix 主应用运行。
